Kết nối GitHub

Trang này lưu thay đổi trực tiếp lên repo tranhoangthu/vn-chill-cam bằng token của bạn. Token chỉ lưu trên trình duyệt này.

Chưa có token.
  1. Mở trang tạo token của GitHub.
  2. Đặt tên token, ở mục Repository access chọn Only select repositories rồi chọn vn-chill-cam.
  3. Ở mục Repository permissions, tìm Contents và chọn Read and write.
  4. Bấm Generate token, sao chép và dán vào ô phía trên, rồi bấm Lưu token.

Danh sách camera

Loại iframe: nhúng trang phát (ví dụ YouTube). hls: link .m3u8. mp4: file video trực tiếp. image: ảnh tĩnh tự làm mới (camera giao thông).

Danh sách kênh radio

Dán link stream trực tiếp. Nếu bạn có file .m3u/.pls, web sẽ tự bóc link bên trong khi phát (một số host chặn thì bạn cần dán link stream gốc).
